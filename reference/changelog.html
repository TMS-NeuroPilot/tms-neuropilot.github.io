Changelog#

The canonical changelog is CHANGELOG.md in the repository. This page summarises the milestones that change how the suite is used.

Unreleased#

Simulator#

  • A new Collision test page runs the selected robot through all project placements in a local MuJoCo scene. It can move the subject head and robot base, jog the coil in world XYZ, choose a shoulder/elbow IK branch, save the start pose to the project and lab profile, and stop at the first collision or IK failure.
  • Four robots now ship with the simulator: Omron TM5X-700, Universal Robots UR5, Han's Robot Elfin E5 (the Aalto / BioMag Helsinki / Tübingen mTMS arm) and Dobot CR5. The tms-robot-control driver names (ur, elfin, elfin_new_api, dobot) are accepted directly in ROBOT.
  • The head phantom follows the project head mesh in the embedded view: browsing, typing, clearing and project loading all update the simulator; clearing returns to the bundled head.stl phantom.
  • The IK chain is now robot-agnostic (active joints are read from the mask, not hard-coded slices), and the scene uses the implicitfast integrator.
  • The MSO is snapshotted when each pulse fires. Precomputed, online and interpolated E-fields all use that snapshot, so moving the slider afterwards cannot rescale an already recorded pulse.
  • The virtual EMG can use DVS (default, parameters in V/m) or TVS (nine coefficients, normalised to the MSO field). Both read the E-field at the configured MEP source element; the Config › Simulation page shows only the selected model's parameters.

GUI#

  • Large project files (head mesh, ROI surface, coil placements, E-field library and EMG source config) are read in background workers. The window stays interactive while they load, each row shows loading..., and Start waits until the reads finish. Changing a path supersedes the older read.

Documentation#

  • This site: 45 pages covering installation, subject data, every GUI page, every configuration key, the workflows and the reference material. Built by a dependency-free generator (docs/site/build.py) and published by GitHub Pages on every push to main.
  • Docs are checked in CI: the build fails on a broken link, an orphan page or a missing navigation entry.

Robustness#

  • The MEP analysis keys (SAMPLING_RATE, CUTOFF_FREQ, TMS_PULSE_TIME, START_MEP, END_MEP, MEASUREMENT_START_TIME) now have defaults in code, so a checkout without .env starts instead of failing at import.
  • The library/placement consistency check now compares matrices stored in either layout ((4, 4, n) or (n, 4, 4)) instead of skipping the comparison when the shapes differ.

Workflows#

  • E-field library generation: scripts/02_create_roi_efield_library.py centres the search on the ROI centroid and derives the radius from the ROI extent (+ margin) automatically; --n-placements 0 keeps the full grid; node-based dA/dt makes a solve ~4× faster; the output carries provenance attributes (mesh, ROI, coil, target/radius source, grid settings).
  • Interpolated E-field mode: the surrogate of Grosshagauer et al. (2025) (code: EfieldInterpolation) is the third E-field mode — dense library plus ROI verification (roi_hash), background load, per-pulse interpolation, and a domain guard whose outside policy is skip-and-exclude (NaN rows). Ships with the auto-centred library generator, a validation script and a ParaView time-series export.
  • The per-pulse regression drops NaN rows (a skipped surrogate pulse) exactly like missing ones.

Earlier unreleased work#

  • Training mode: neuropilot training runs the real stimulator and InVesalius with a virtual EMG and no robot; the operator holds the coil.
  • Config › Simulation: the five VIRTUAL_MEP_* keys, with the MEP source summary linked to the project.
  • Robot registry — one RobotSpec per robot; --list / --check; the Config › Lab selector stores the key and reports unknown values.
  • Five colour themes — Workstation Light, Lab Paper, Instrument Blue, Graphite, Midnight; switchable live from Config › Lab; contrast enforced by tests.
  • Lab profile — hardware settings in ~/.neuropilot/lab.yaml, edited in Config › Lab, with .env as the override layer.
  • E-field mode switching — per-pulse E-field rows let the mode change mid-session; the pulse is held while the online solver warms up.
  • Config › Study — a study profile with Apply to session, and a clear split between what applies immediately and what needs a restart.
  • Project file carries the E-field mode (efield_mode).
  • Test suite: more than 800 tests, GUI tests behind a gui marker, six-page snapshot baselines, property/fuzz tests for the .env editor.

0.1.0 — 2026-11-10#

The first release of the merged suite:

  • neuropilot sim runs the whole simulated stack in one command.
  • The controller drives the seven-step mapping loop against InVesalius, the robot controller and the stimulator.
  • Precomputed and online E-fields, with the online solver in a separate worker.
  • MEP extraction through pynibs, nine fit functions, R² maps on the cortical surface.
  • Results CSV, placement log, plot folders, screenshots and CSV export.
  • CI: syntax gate and headless tests.

How versions are handled#

The suite is pre-1.0. The changelog records behaviour changes that affect a session or an existing configuration; internal refactors are not listed. When a change requires action, the entry says so explicitly.
