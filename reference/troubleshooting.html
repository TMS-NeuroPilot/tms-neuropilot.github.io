Log colors#

The supervisor colors only the role label inside square brackets, for example [controller], [invesalius] and [relay]. Set NO_COLOR to disable this, or FORCE_COLOR=1 to keep the colors when output is redirected to a file. Repeated simulated-relay forwarding lines are coalesced; on a terminal the latest line is updated in place, while redirected output emits one summary when the burst ends.

What to collect before asking#

  1. The terminal log with role prefixes ([relay], [nav], [robot], [controller]), from the start of the run.
  2. The step where it failed and the last 20 lines of the Control log.
  3. python -m neuropilot.sim_robot.robots --check <key> output.
  4. pytest -m "not gui" -q tail, if the problem is reproducible without hardware.
  5. The project YAML (redact paths if needed) and the E-field shapes: E_mag.shape, ROI triangles, placements.
