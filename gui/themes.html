Themes and display#

Five colour themes ship with the controller. They are not skins: every theme defines the same token table, and the style sheet, the charts, the 3-D viewport, the status LEDs, the mode badge and the log bed are all generated from it.

Switch a theme#

Config › Lab › Theme. The change applies immediately — no restart — and is written to ~/.neuropilot/lab.yaml as UI_THEME, so the next session opens with it.

You can also pin it from .env:

bash
UI_THEME=Graphite

.env wins over the lab profile, like every other key.

The five themes#

Theme Character Good for
Workstation Lightcool neutral canvas, amber accentthe default; screenshots, daylight
Lab Paperwarm ivory paper, terracotta accentbright rooms, figures for a manuscript
Instrument Bluecool slate, deep instrumentation bluekeeps amber free to mean "warming up"
Graphitedark, neutral two-level charcoallong sessions in a dim room
Midnightdark, blue-black with a cyan accentnext to a bright neuronavigation screen

The two dark themes are not inverted lights: they define their own status colours and chart series so a red LED is still red, and the accent still passes contrast on the dark canvas.

What a theme controls#

Every entry in controller/theme.py is a token:

Group Tokens
textink, muted, soft, mono
surfacescanvas, card, line, edge, edge_hover, hover
accentaccent, accent_dark, accent_soft, accent_disabled, on_accent
disableddisabled_bg, disabled_edge, disabled_ink
statusok, ok_soft, warn, danger, danger_soft, danger_edge
instrument bedsbed, bed_ink, bed_muted, bed_sel
miscscroll, scroll_hover, led_off, grid
chartsseries (six colours)

The style sheet is built from these; MeshWidget.apply_theme, MplGraphWidget.apply_theme and the LED renderer use the same table. That is why changing the theme does not leave a light-coloured plot on a dark window.

Contrast is enforced#

tests/test_theme.py computes WCAG contrast ratios from the tokens:

  • body text on card and canvas ≥ 7:1,
  • captions (muted) and status colours ≥ 4.5:1,
  • white text on the accent ≥ 4.5:1 (or the theme must set on_accent to a dark colour, which the dark themes do).

A theme that fails these numbers fails CI. If you add a theme, run:

bash
pytest tests/test_theme.py -q

UI scale#

The window is laid out for 1244×960 and scales with the screen. Force a scale when the automatic choice is wrong:

bash
NEUROPILOT_UI_SCALE=1.25       # in .env
Value Effect
unsetscale from the screen's DPI
1.0design size
1.25, 1.5, …larger fonts and controls
below 1.0clamped to 1.0; shrinking breaks the card layouts

The UI scale is applied at start; changing it needs a restart.

Display details#

Element Behaviour
Tab stripfollows the theme's card colour, including the LED corner
Log beddark instrument surface in every theme, for readability
Robot viewdark bed; the MuJoCo scene is rendered by VTK with its own lighting
Chartsseries palette from the theme, grid from grid
3-D scalar barrecoloured with the theme's ink and card colours
Screenshotsthe exported PNG includes the corner overlays and the current theme

Accessibility#

  • The theme names are plain descriptions, not brand names; the combo is keyboard-navigable.
  • Every status is text (OK, ERROR) as well as colour, so a colour-blind operator does not lose information.
  • The contrast tests above are the objective floor; they do not replace a check on the actual monitor in the lab.
