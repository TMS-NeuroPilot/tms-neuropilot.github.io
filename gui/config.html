Config page#

Config collects the four configuration scopes in one place:

Sub-tab Scope File it edits
Lab (hardware)this machine~/.neuropilot/lab.yaml (+ a few .env keys)
Study (mapping)this protocola study YAML, applied to the session
Subject (files)this subjectthe project YAML, via the Project page
Simulationthis machine's simulated MEP.env (VIRTUAL_MEP_*)

The precedence between the files is on Settings model; this page documents the controls.

Save and reload#

  • Save lab profile writes lab.yaml and the analysis keys shown on the Study tab (EMG_CHANNELS, SAMPLING_RATE, CUTOFF_FREQ, TMS_PULSE_TIME, START_MEP, END_MEP) to .env, preserving comments and unknown keys. That split is deliberate: hardware is portable between projects, the analysis windows are read at import and must live where the bootstrap reads them.
  • Reload re-reads lab.yaml and .env and marks every field that .env overrides.
  • The status line reports the file and the override count: Loaded lab.yaml (~/.neuropilot/lab.yaml) · 2 key(s) overridden by .env.
  • Saving says: Saved lab.yaml — restart TMS NeuroPilot to apply. The theme is the exception: it applies before you save.

⚠.env wins

A key that .env defines cannot be changed from this page: the field is written to lab.yaml, but the next start still reads the .env value. The tooltip says so, and the status line counts them. Remove the line from .env (or change it there) if the GUI value should win.

Simulation#

The Simulation page tunes the virtual EMG. It is used in simulation and training modes; the fields are disabled in real and manual modes. The controller reads the values when it starts, and Save simulation settings writes .env, so restart to apply.

Field Key Default Unit
ModelVIRTUAL_MEP_MODELdvsdvs / tvs
Noise sigmaVIRTUAL_MEP_NOISE_MV0.001mV
Trial-to-trial variabilityVIRTUAL_MEP_TRIAL_VARIABILITYtrueon/off
Motor thresholdVIRTUAL_MEP_MT60V/m (no-response cutoff)
Upper limitVIRTUAL_MEP_UPPER_LIMIT100V/m (TVS normalisation)
E-field scale (dI/dt)VIRTUAL_MEP_EFIELD_SCALE1.4factor

The model selector swaps the parameter panel below the common fields:

  • DVS: x0 and r in V/m, sigma_x in V/m, amp/y0 in mV, sigma_y in log10 units.
  • TVS: all nine coefficients. p1/p2 are log10 terms; p3–p7 are linear values, p8 is V, p9 is dimensionless.

The selected model reads the E-field at the channel's configured MEP source element. DVS uses the field directly in V/m; TVS uses E / upper limit as its MSO-normalised input. Only one model's panel is shown at a time.

The MEP source itself is project data: the cortical element per channel is assigned in the project, not here. The page shows the configured channel names and the EMG sources file. Edit in Project opens the Project tab; the source elements stay with that subject. See EMG channels and MEP windows for the model and the key descriptions.
