Control page#

The Control page runs the session: stimulation settings, the E-field mode, the transport buttons, the robot view and the log.

Transport row#

Button Action Notes
Move Coil Upstop, pause, retract the robotthe safest way to interrupt
Backrepeat the previous targetignored while a pulse is in flight
Start / Pausestart the mapping; while running, pause before the next pulsethe label toggles
Nextskip the current targetimplemented as skip → COMPLETE
Finishend the session after the current stepalways enabled during a run

In the top-right corner of the robot view: Total targets (the length of the order list) and Current (the pulse counter and the active target).

Stimulation card#

Control Range Effect
Amplitude slider + spin0–100 % MSOsets the stimulator output; the slider and spin mirror each other
Repetitions1–100pulses per target
Min. interval1–60 sminimum ISI, measured on the monotonic clock
Pulse shapeBiphasic / Monophasicstimulator waveform
Enable—arms the stimulator for a single manual pulse
Fire—fires one pulse; only after Enable

⛔Safety: amplitude changes reach the stimulator

Moving the amplitude slider sends set_amplitude_stim immediately. Confirm the value on the stimulator itself before the first pulse, and never change it while a pulse is in flight.

The Fire button is for testing a single pulse outside the loop. It is gated on Enable and is independent of the mapping; arming does not start a session.

E-Field card#

Control Meaning
Precomputed E-Fielduse the library loaded in the project
Online E-Fieldsolve the field per pulse with SimNIBS
Interpolatedinterpolate the field from the dense library (surrogate_library_path), with a domain guard
hint linewhat the mode is doing now (see E-field modes)

Start is disabled until a mode is selected. The mode is switchable during a run; pulses are held while the online solver warms up or the interpolated library loads.

Robot card#

Control Meaning
Enable free drivelet the operator move the arm by hand (robo mode)
Default speedspeed while travelling between targets, %
Tuning speedspeed near the head, %

Both speeds are pushed to the robot when a session starts, so the robot runs with the values shown in the GUI rather than its power-on defaults.

Log card#

A read-only log of the state machine:

text
=== BEGIN TARGET 000 (1/1) ===
Sending target to InVesalius!
Tracking target with robot!
Stopping target tracking.
Firing Stimulator!

Health holds, skipped pulses, aim-error warnings and analysis messages appear here too. The same lines are printed to the terminal.

Robot view#

In simulation the lower right shows the MuJoCo scene: the arm, the head model and the coil. It is a rendering of the robot's joint state, not a measurement.

In real, manual and training modes there is no robot scene.

Button gating#

Condition Effect
no E-field modeStart, Next, Back, Move Coil Up disabled
precomputed mode without a librarysame
online mode while the solver warms upStart disabled until ready
a system in errorStart disabled; during a run the loop holds
run in progressFinish always enabled

Keyboard and accessibility#

The window scales with NEUROPILOT_UI_SCALE; see Themes and display. The buttons expose their labels as accessibility names, and the log is selectable text so it can be copied into a bug report.
