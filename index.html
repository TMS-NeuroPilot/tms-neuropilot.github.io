TMS NeuroPilot

Running optimized TMS mapping experiments with per-pulse electric fields, online analysis, InVesalius neuronavigation and a complete virtual twin.

Python 3.11 PyQt5 + asyncio SimNIBS 4.5 InVesalius 3.1 GPL-3.0-or-later

TMS NeuroPilot guides the experimenter through a mapping experiment: the coil is held by hand (manual mode) or by a TMS robot (robo mode, via tms-robot-control), while the software collects the EMG responses and runs element-wise mapping analyses online. That enables high-resolution structure-function mapping (Numssen et al., 2021; Weise et al., 2023).

It integrates with InVesalius neuronavigation to guide the coil across many placements, controls the stimulator, and uses SimNIBS for online E-field calculations. Experiments can use different optimization schemes, for example FPS (Schultheiss et al., 2025) or D-optimal (Qiu et al., 2026; Numssen, Qiu et al., 2026), and the analysis runs online; single trials can be excluded by hand and the full data set exported. The software is open source and can be adapted to local hardware, outcome metrics and new optimization schemes.

A full virtual-twin mode allows extensive testing of new optimization schemes under realistic conditions (noise, individual morphology, experimental demands and session duration) to dry-run robotic experiments or to train experimenters on simulated MEPs and realistic tracking.

What it does#

A mapping session is a loop over pulses:

  1. The controller takes the next target from the target order.
  2. It creates that target as a marker in the neuronavigation.
  3. The robot, or the operator in manual mode, moves the coil there.
  4. The stimulator fires.
  5. The EMG is cut into a window around the pulse and reduced to a peak-to-peak MEP.
  6. The pulse's E-field is read from the precomputed library or solved online for the realised coil pose.
  7. For each ROI element, the MEPs are regressed against |E| at that cortical location across all trials, and the R² map is updated. The map supports localisation of the cortical source; it is not a significance test.

This 'voxel-wise' mapping approach can also be applied to map other responses, such as phosphene production, reaction time, or heart-brain coupling in other functions and brain regions.

Run the simulator in three commands#

bash
conda activate neuropilot
pip install -e . --no-deps          # once, from the repository root
neuropilot sim                      # relay → nav + robot → controller

When the TMS NeuroPilot GUI has loaded, load the ernie example project and press Start.

💡No hardware required

The simulated stack is the recommended way to learn the interface. It runs the same controller code, the same relay protocol and the same state machine as a real session; only the relay, neuronavigation and robot are virtual twins.
