The mapping loop#

The controller is a state machine. Each target runs INIT → … → COMPLETE; the loop then moves to the next repetition or the next target. This page documents the steps, the gates and the escape hatches.

The steps#

Step What it does Leaves when
INITthe state before the first target; per-target flags are reset by reset_algorithm()immediately
SEND_MARKERsends External Controller to Neuronavigation: Create Marker with the target pose and a labelafter the message is queued
START_TRACKINGwaits 3 s for the neuronavigation to accept the marker, then sends Press robot button (skipped in manual mode)after 3 s
WAIT_FOR_TARGET_REACHEDwaits for Coil at target, force above threshold (robot mode) and the minimum intervalall three hold
FIRE_STIMfires the stimulator; records the fire time on the monotonic clockthe stimulator accepted the command
COLLECT_DATAwaits for the realised pose, reads the EMG, extracts the MEP, stores the E-field rowthe pulse is recorded (or skipped)
ANALYSEappends the pulse and triggers a background fit every third pulseimmediately
COMPLETEnext repetition, next target, or the end—

The per-frame loop calls the matching <name>_step function and sleeps 50 ms between iterations. Every step must return quickly; the slow work (FEM, EMG reads, fits) runs in executors or background tasks.

The gates in WAIT_FOR_TARGET_REACHED#

A pulse is fired only when all of these are true:

  1. Coil at target — the neuronavigation confirmed the realised pose (From Neuronavigation: Coil at target).
  2. Force — the robot's force reading exceeds pressure_thresh (1). Manual mode skips this gate.
  3. ISI — at least minium_isi seconds have passed since the previous pulse, measured on the monotonic clock so a system-time jump cannot shorten it.

The step keeps the robot's press button active while it waits and releases it when it advances (Stopping target tracking.).

Escape hatches#

Action Implementation Result
Next (skip)switch_step("skip") → COMPLETEthe current target is abandoned; the next order entry starts
Backswitch_step("previous") → decrement the order index, reset repetitionsthe previous target is repeated
Pausechecked before the pulse and between targetsthe coil stays on target
Finishis_finished = Truethe loop ends after the current step; results are written
Move Coil Upstop + pause + Set objective: 2the robot retracts
step raises_abort_run()the run stops, the error is logged, collected data is kept

Back is ignored while the pulse is in flight:

text
Previous ignored: a pulse is in flight.

Finish and Next work even when a system is unhealthy. The health gate only blocks the work steps, never the operator's ability to stop.

Health holds#

Before each work step the controller checks all systems. If one is in an error state the loop holds:

text
Held at WAIT_FOR_TARGET_REACHED: robot not ready. Finish ends the session.

When the system recovers:

text
All systems ready again, continuing.

This is deliberate: a dropped EMG or robot should not silently abandon a session, and it should not keep stimulating either.

Repetitions and ordering#

  • The target order is a list of 0-based placement indices.
  • n_repetitions repeats the same target before advancing.
  • Without an order file the controller visits every placement in file order.
  • current_target_order_idx is the position in the order list; it is what the status line shows as pulse N.

What is reset per target#

reset_algorithm() clears the flags that belong to one pulse: target reached, target created, realised target, the previous pulse's fire time, the "go back" flag and the per-step log state. A new flag added to the loop must be reset there, or it leaks into the next target.

Failure semantics#

  • One failing step aborts the run, not the process: the error is logged with a traceback, aborted_by is set, and the results collected so far are kept.
  • A failed analysis is logged but does not abort the run.
  • A missing realised pose after COLLECT_TIMEOUT_S skips the pulse: No realized target after 20 s -- pulse skipped.
  • A missing EMG file is recorded without a MEP: [WARN] no new EMG file for this pulse …
